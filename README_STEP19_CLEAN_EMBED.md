# Step 19 Clean Embed Package

This package is a cleaned version of the portfolio website with the Hugging Face Streamlit assistant embedded on the Ask page.

## Live assistant URL

https://ramparagi-ask-ram-portfolio-streamlit.hf.space

## Important

Do not upload the older nested folder named `portfolio_step16_work`. It contained the old preview Ask page.

Upload only the contents of this package.

## Files to upload

- `index.html`
- `artifact.html`
- `styles.css`
- `capability-map-home.png`
- `src/`
- `content/`

## After upload

Open the website and test:

- `/#/ask`
- `/#/library`
- `/#/capabilities`

If the Ask page still says preview model not connected, the old `src/pages.jsx` is still deployed or cached. Replace `src/pages.jsx` from this package and hard-refresh the browser.
